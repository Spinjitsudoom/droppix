# Client-declared Monitor Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each tablet declares a grid cell `(col,row)` over HELLO v6; the host positions that tablet's evdi output at `primary.right + col×w, primary.top + row×h`, arranging the existing per-tablet monitors into a grid. `(0,0)` = today's placement.

**Architecture:** HELLO v6 carries `wall_col/wall_row` (mirrors the v5 bitrate addition at every layer). The streamer computes a position from the cell + its own size + the primary anchor (pure `grid_position`) and places its output via a new `place_output` backend call (X11 `--pos` / KWin `position.<x>,<y>`, extending the mirror-mode positioning). **Host + both clients; no capture/encode change.**

**Tech Stack:** C++ (host, Qt6 GUI + Linux client), Kotlin/Android, CMake, Gradle.

## Global Constraints

- **HELLO v6** (this IS a protocol change): append `u16 wall_col, u16 wall_row` after the v5 `bitrate_kbps`, before the name/id strings. Version-gated: only encoded/decoded when `version >= 6`; pre-v6 bodies → `(0,0)`. Bump `kProtocolVersion` / `Protocol.VERSION` to **6**. C++ ↔ Kotlin byte-identical; update `WIRE.md` + the HELLO test vectors.
- **Back-compat direction:** a new host decodes old (v5/v4/v3/v2) bodies with `wall=0` (as v5 does today). Host+client ship together.
- **Uniform grid:** `grid_position(col,row,own_w,own_h,anchor_x,anchor_y) = {anchor_x + col*own_w, anchor_y + row*own_h}`. `(0,0)` = the anchor (right-of-primary) = current behavior.
- **No capture/encode/input change** — Touch/Scroll/Key/Pen untouched; only HELLO + output placement + client settings.
- **Build/test envs** (repo on CIFS no-exec mount):
  - Host: `distrobox enter droppix-dev -- bash -lc 'cmake --build ~/droppix-build -j && ctest --test-dir ~/droppix-build <-R filter> --output-on-failure'` (configure once with `-DDROPPIX_BUILD_TESTS=ON`).
